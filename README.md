# AVC Public Access

Source repository for the AVC Public Computer Access system.

## Projects

- `AVCPublicAccess.Client` - Windows public-computer client UI
- `AVCPublicAccess.Server` - Web/server application
- `AVCPublicAccess.Service` - Windows background service
- `AVCPublicAccess.Watchdog` - Watchdog component
- `AVCPublicAccess.slnx` - Solution

## Important

This repository contains source code and project configuration.

Generated build output, deployment packages, historical backups, and machine-specific files are intentionally excluded.

Changes should be made against source code and tested before creating production deployment packages.
